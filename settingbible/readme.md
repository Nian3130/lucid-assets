# Current / Canon

## 루시드 (Lucid)
- 루시드는 현실과 동일한 물리적 구조를 공유하지만,  
  서로 다른 규칙과 경계가 작동하는 **현실의 이면세계**를 통칭한다.
- 외형·지형·문명은 현실과 유사하게 관측되나,  
  사건·변칙·개입은 루시드 고유의 규칙에 따라 발생한다.
- 루시드는 단일한 세계가 아니라,  
  공통된 규칙군과 계층 구조를 공유하는 **복수의 이면세계 집합**으로 분류된다.

## 세계 개요
- 현실세계는 관측과 판단의 기준이 되는 **기준면(Reference Plane)** 이다.
- 루시드는 현실세계의 **이면세계**이기 때문에,  
  구조적으로 현실의 **하위 계층**으로 분류된다.
- 루시드는 현실세계의 하위에 존재하는 **다층 구조(Layers)** 로 구성되며,  
  각 계층은 인간 중심 규칙의 유지 정도와 개입 가능성에 따라 구분된다.
- 현실세계와 루시드 사이에는 **공명지대(Resonance Zone)** 라는 완충 지대가 존재한다.
- 현실에서 루시드가 관측되는 조건과 방식에 관한 정보는  
  **현재 비공개**로 분류된다.

## 레이어 구조
- 공명지대 (Resonance Zone):  
  현실과 루시드 사이에 위치한 완충 지대.  
  게이트 개방과 변이체 발생을 포함한 각종 사건·사고가 끊임없이 관측되는 지역이다.
- 흔적계 (Trace Layer):  
  현실세계와 유사한 구조를 지닌 루시드의 페러렐월드형 이세계로,  
  조건부 인간 거주가 가능하며 안전지대가 유지된다.
- 미공개지대
  - 심층계 (Deep Layer):  
    미공개지대. 상세 규칙·개체·지형 정보는 공개 기록에서 제외된다.  
    일부 내용은 전승 형태로 전해지나, 신뢰성은 보장되지 않는다.
  - 기원계 (Origin Layer):  
    미공개지대. 규칙 개입 및 권한과 관련된 사항은 접근 제한 대상이다.  
    설령 기록이 존재하더라도, 그 신뢰성은 보장되지 않는다.

## 세력 구도 변천

### 과거
- 루시드를 무대로 활동한 이들의 주요 역할은  
  **기원자 / 균형자 / 이탈자 / 표류자 / 모험가**의 다섯 분류로 인식되었다.
- 이 분류는 역할과 태도를 기준으로 한 개념적 구분이었으며,  
  명확한 세력 단위나 조직을 전제로 하지는 않았다.

### 현재
- **기원자 (Originator):**  
  현재는 관측 및 직접 개입이 극히 어려운 상태로 분류된다.

- **여명 (黎明 / Dawn, 던):**  
  균형자·표류자·모험가가 결성한 연합 세력.
  여기에 속한 이들을 **헌터**로 불린다.
  이탈자의 확장과 침식을 저지하고,  
  루시드와 현실의 균형을 수복하는 것을 공동 목표로 한다.

- **일식 (日蝕 / Eclipse, 이클립스):**  
  이탈자의 우두머리 **카미야**의 주도하에 이탈자가 결집하여 형성된 세력.  
  경계를 오용하거나 재구성하며, 기존 질서의 붕괴와 새로운 구조의 정착을 추구한다.
  헌터 측에서는 이들을 **빌런**이라 정의하고 있다.
