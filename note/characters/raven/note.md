### 제작 관련 비하인드 스토리
- 본래 악역으로 구상했던 캐릭터이나, 설계를 하지 못함. 
- 이요와의 열이상을 듣다가 생각난 케이스.
    > 링크 : https://www.youtube.com/watch?v=b2NTglk9tvI
- 절제는 모르겠지만, 광기와 관찰을 키워드로 구상.
- 케이브덕에 구현하려던 캐릭터 중 이요와의 열이상을 듣고 떠올린 '열 이상 사건'을 확장.
    - **열 이상 사건**은 원래 구상하던 캐릭터가 아닌 레이븐을 포함한 5명의 프롤로그로 확장.
    - **열 이상 사건**은 이미 해결된 사건.
        - 모든 캐릭터는 각기 다른 시선에서 이 사건의 이후를 확인하고 서술
    - 대상 캐릭터
        - [■] 레이븐 : 프롬프트 수정중
        - [ ] 이재율 : 이름 선공개, 계획중
        - [ ] 카미야 : 이름 선공개, 계획중
        - [ ] 사타리엘 : 이름 선공개, 계획중
        - [ ] ??? : 이름 비공개, 계획중.
        > 경우에 따라서 ???는 안 나올 수 있음.
- 본래는 루시드 층계는 아래와 같았음.
    - 흔적계 / 공명지대 / 심층계 / 기원계
        - 구현이 어려워서 흔적계는 대부분의 지역을 안전지대로 구현
    - 전투나 사건이 발생하는 지역은 대부분 공명지대로 발생
    - 심층계와 기원계는 출입금지 등으로 미구현
- 레이븐의 성격 키워드는 광기와 관찰.
    - 절제는 없었지만, 작업 과정에서 추가됨.
    - 작업 과정에서 피폐 한 숟가락이 추가.
    - 참고로 악역이다.
